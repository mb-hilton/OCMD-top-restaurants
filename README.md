# OCMD-top-restaurants
Top restaurants in Ocean City, MD broken down

## View the Interactive Map

Check out the interactive restaurant map! The map is powered by Leaflet and displays restaurants categorized by type (Raw Bar, Steamed Crabs, Sushi, Breakfast, Italian, Seafood, Kid-Friendly, and Ambiance).

**To enable GitHub Pages to serve the map:**
1. Go to your repository settings
2. Navigate to **Pages** 
3. Under "Build and deployment", select **Deploy from a branch**
4. Choose `main` branch and `/docs` folder
5. Save

The map will then be available at: `https://[your-username].github.io/OCMD-top-restaurants/`
